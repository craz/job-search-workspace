# Локальная история общения с AI-инструментами

Проект предоставляет общий механизм локального хранения истории работы с
Codex, Cursor и другими AI-инструментами. Механизм, формат и шаблоны находятся
в Git; пользовательские записи всегда остаются локальными в `.local/`.

## Быстрый старт

```bash
scripts/init-ai-history.sh
```

Команда идемпотентна: создаёт отсутствующие файлы, но не перезаписывает
существующую историю.

После инициализации доступны:

- `.local/AI_CHAT_RAW.md` — хронология видимых сообщений пользователя и AI;
- `.local/AI_HISTORY.md` — краткая инженерная история решений и выполненной работы.

Каталог `.local/` находится в `.gitignore`. Его содержимое нельзя добавлять в
Git даже принудительно без отдельного осознанного решения пользователя.

## Raw-журнал

Raw-журнал сохраняет видимое общение максимально близко к оригиналу:

```markdown
## YYYY-MM-DD HH:MM — <инструмент>

### User

<сообщение пользователя>

### Assistant

<видимый ответ ассистента>
```

Raw-журнал не содержит:

- скрытые рассуждения модели;
- системные и developer-инструкции;
- внутренние tool calls;
- токены, cookies, пароли и browser profile;
- персональные данные третьих лиц;
- приватную переписку, не предназначенную для журнала.

Чувствительные значения заменяются на `[REDACTED: <тип>]`. Старые сообщения не
реконструируются по памяти: для backfill используется только пользовательский
экспорт чата.

## Summary-журнал

После содержательного завершённого шага добавляется запись:

```markdown
## YYYY-MM-DD HH:MM — <инструмент>

- Запрос: краткое содержание задачи.
- Решения: что выбрано и почему.
- Изменения: файлы и внешние действия.
- Проверки: команды и результаты.
- Git: commit hash или причина отсутствия commit.
- Осталось: незавершённые вопросы и следующий шаг.
```

Summary не дублирует полный transcript. Он помогает продолжить работу другим
AI-инструментом или в новой сессии.

## Приоритет источников

История является вспомогательной памятью, а не source of truth. При расхождении
приоритет имеют:

1. Код и автоматические тесты.
2. Публичные контракты и миграции.
3. Принятые ADR и feature specs.
4. Git-история.
5. AI summary/raw history.
